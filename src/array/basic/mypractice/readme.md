📘 Advanced Array Management System – Version 3 Ultra Pro

A fully-featured, menu-driven Java Array Management System that supports dynamic array operations, sorting algorithms, statistical calculations, duplicate management, file storage, and advanced input validation.

This is the Ultra Pro Version (V3) — the most powerful version in the complete array project series.

🚀 Features
1. Array Creation & Initialization

Safe input using exception handling

Prevent invalid size values

Accept array values with validation

🔧 2. Core Array Operations
Feature	Description
Insert	Insert new value dynamically by resizing array
Update	Modify a value at any valid index
Delete	Remove an index and shrink array
Search	Linear search with index display
Display	Show index, memory hash address & stored value
📊 3. Sorting & Algorithms

Ascending sort (custom implementation)

Descending sort

Reverse array

📈 4. Statistical Operations

Find maximum

Find minimum

Sum of all elements

Average value

Frequency count for a value

🧹 5. Duplicate Handling

Detect duplicate values

Remove duplicates

Print unique elements only

📂 6. File Operations (Ultra Pro – NEW)

Save array to .txt file

Load array from file to restore saved data

⚙ 7. System Utilities

Dynamic array resizing (ArrayList-like)

Fully modular code (each operation in different method)

Strong input validation (no crashes)

Structured menu-driven interface
